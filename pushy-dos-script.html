📋 Copy the scoreboard loader

This short loader is the only thing that ever needs to go into Apps Script. After it's in, scoreboard updates happen on their own.

  1. Tap Copy script above.
  2. In the Google Sheet: Extensions → Apps Script.
  3. Next to Files, tap ＋ → Script and name it Loader.
  4. In the new file, tap on an empty line below the existing lines, hold, and tap Paste.
  5. In the Files list, tap ⋮ next to Code.gs → Delete. (Delete every file except Loader.)
  6. Tap Save, then Deploy → Manage deployments → ✏️ → Version: New version → Deploy, and allow access when asked.

If the button doesn't work, the script is also below. Tap inside it, then Select All and Copy.
